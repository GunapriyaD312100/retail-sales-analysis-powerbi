# Retail Sales Analysis Dashboard

## Project Overview

An interactive Power BI dashboard designed to analyze retail sales,
profitability, orders, quantity, regional performance, and product performance.

## Tools Used

- Power BI
- Power Query
- DAX
- Excel / CSV
- Data Visualization

## Key Analysis

- Total Sales
- Total Profit
- Profit Margin
- Sales Trend by Year
- Sales by Sub-Category
- Profit by Region
- Category Performance
- Product Profitability

## Dashboard

![Retail Sales Dashboard](Retail_Sales_Dashboard.png)

## Key Insights

- Analyzed overall sales and profitability.
- Compared regional profit performance.
- Identified high-performing sub-categories.
- Analyzed product-level profitability.
- Identified products with negative profit.
